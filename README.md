# 박수연 | 디자인 포트폴리오

## 소개
간단하고 직관적인 인터페이스와 사용자 동선에 관심이 있는 박수연입니다.

AX해커톤에서 외국인 고객을 위한 은행 앱 가이드 서비스의 UI/UX 디자인과 AI 홍보 영상 제작을 담당했습니다. 화면 디자인뿐 아니라 AI 이미지·영상 생성, 편집, 자막 작업을 수행하며 서비스의 이용 흐름과 가치를 전달하는 작업을 경험했습니다.

## 기술 사용 맥락

| 도구 | 프로젝트에서 사용한 방식 |
|---|---|
| **Figma** | 은행 앱과 AI 화면 안내 흐름을 표현하는 UI/UX 화면 디자인 |
| **Adobe Firefly** | 홍보 영상에 사용할 이미지와 영상 장면 생성 |
| **ChatGPT** | 원하는 움직임을 표현하기 위한 영상 생성 프롬프트 보완 |
| **Adobe Premiere Pro** | 생성한 이미지와 영상 편집, 자막 작업 |

## 대표 프로젝트 — 외국인 특화 스마트 화면 가이드 챗봇

### 프로젝트 개요
외국인 고객이 은행 앱에서 겪는 언어와 금융 절차의 어려움을 줄이기 위해 기획한 서비스입니다.

AI가 고객의 막힘을 감지하고, 필요한 화면을 Spotlight로 강조해 안내하며, 해결되지 않으면 이용 기록과 함께 상담원에게 연결하는 흐름을 구상했습니다.

- **프로젝트:** AX해커톤
- **진행 기간:** 3일
- **팀 규모:** 5명
- **진행 상태:** 완료
- **나의 역할:** UI/UX 디자인 및 AI 홍보 영상 제작

### 대상과 문제
한국어 금융 용어와 국내 은행 절차에 익숙하지 않은 외국인 고객을 주요 대상으로 설정했습니다.

- 안내 문구와 오류 메시지를 이해하기 어렵습니다.
- 설명을 읽어도 실제 화면에서 다음 행동을 찾기 어렵습니다.
- 문제가 생겼을 때 자신의 상황을 설명하기 어렵습니다.
- 상담원 연결 후 이전에 시도한 과정을 다시 설명해야 합니다.

위 내용은 프로젝트에서 설정한 문제이며, 사용자 조사로 검증한 결과는 아닙니다.

### 화면 이용 흐름
**은행 홈 → AI 대화 → 안내 시작 → Spotlight 화면 안내 → 업무 완료**

외국인 고객에게는 간단하고 직관적인 인터페이스가 필요하다고 판단했습니다. 사용자가 다음 행동을 쉽게 파악할 수 있도록 화면 구성과 동선을 고려했습니다.

## 개인 기여와 팀원 기여

| 구분 | 작업 내용 |
|---|---|
| **개인 기여 — UI/UX** | 은행 홈, AI 대화, 안내 시작, Spotlight 안내, 업무 완료 화면 등 5개 화면 디자인 |
| **개인 기여 — 홍보 영상** | 이미지 제작, AI 영상 생성, 영상 편집 및 자막 작업 |
| **팀원 기여 — UI/UX** | 제가 제작한 디자인을 추가로 발전시켜 최종 디자인 완성 |
| **팀원 기여 — 홍보 영상** | 영상 스토리보드 작성 |

최종 디자인은 제 작업본을 바탕으로 팀원이 추가 작업한 공동 결과물입니다. 개인 작업본과 팀의 최종 디자인을 구분해 제시합니다.

## 작업 과정

### 1. 사용자 동선을 고려한 UI/UX 디자인
Figma로 주요 화면 5종을 디자인했습니다. 은행 홈에서 AI에 질문하고 화면 안내를 시작한 뒤 업무를 마치는 흐름을 구성했습니다.

Spotlight 안내 화면에서는 주변 화면을 어둡게 하고 특정 영역을 강조해, 사용자가 다음에 선택할 위치를 알 수 있도록 표현했습니다.

### 2. 협업을 통한 디자인 발전
제가 제작한 화면에 다른 팀원이 추가로 디자인 작업을 진행해 최종안을 완성했습니다. 이 과정에서 개인 작업이 팀의 결과물로 이어지는 협업을 경험했습니다.

### 3. AI 이미지와 영상 생성
팀원이 작성한 스토리보드를 바탕으로 Adobe Firefly에서 이미지와 영상 장면을 생성했습니다.

생성 영상의 움직임이 부자연스럽거나 원하는 동작이 나오지 않을 때는 ChatGPT에 질문하며 프롬프트를 보완하고 다시 생성했습니다. 이를 통해 의도한 움직임이 반영된 장면을 제작했습니다.

### 4. 편집과 자막 작업
Premiere Pro에서 생성한 이미지와 영상 장면을 편집하고 자막을 추가해 홍보 영상을 완성했습니다.

## 결과물과 근거

| 자료 | 확인할 수 있는 내용 | README 반영 상태 |
|---|---|---|
| **개인 UI/UX 작업 화면 5장** | 직접 디자인한 화면 구성과 안내 흐름 | GitHub 업로드 후 첨부 예정 |
| **팀원 수정 최종 화면 1장** | 개인 작업 이후 팀에서 발전시킨 디자인 | GitHub 업로드 후 첨부 예정 |
| **AI 홍보 영상 파일** | 영상 제작 결과물 | 업로드 또는 공유 링크 추가 예정 |

현재 정리는 첨부된 디자인 이미지와 본인의 작업 설명을 기준으로 작성했습니다. 홍보 영상은 파일이 제공됐지만 내용에 대한 직접 검토는 이루어지지 않았습니다.

프로젝트는 완료했으며, 자동 막힘 감지와 상담원 연결 기능의 실제 작동 범위, 사용자 테스트 결과, 서비스 배포 여부는 현재 자료에서 확인되지 않았습니다.

## 배운 점과 개선 계획

### 배운 점 — 협업
제가 만든 디자인이 다른 팀원의 작업을 거쳐 최종안으로 발전하는 과정을 경험했습니다. 이번 프로젝트에서 얻은 주요 배움은 협업이며, 개인이 맡은 작업을 팀의 결과물로 연결하는 경험을 할 수 있었습니다.

### 개선 계획 — 직관성과 시각적 완성도를 함께 고려하기
이번 디자인에서는 사용자가 쉽게 이해할 수 있는 화면과 동선을 우선했습니다. 그 과정에서 시각적인 아름다움까지 충분히 발전시키지 못한 점이 아쉬움으로 남았습니다.

앞으로는 직관적인 사용 흐름을 유지하면서 색상, 타이포그래피, 여백과 구성의 조화를 함께 검토해 디자인 완성도를 높이고자 합니다.

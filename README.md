# 박수연 | UI/UX 디자인 · AI 콘텐츠 제작

## 소개

간단하고 직관적인 인터페이스와 사용자 동선에 관심이 있는 박수연입니다.

AX해커톤에서 외국인 고객을 위한 은행 앱 가이드 서비스의 UI/UX 화면과 AI 홍보 영상을 제작했습니다. 제가 만든 디자인을 다른 팀원이 발전시켜 최종안으로 완성하는 협업을 경험했습니다.

## 사용 도구와 작업 맥락

| 도구 | 실제 활용 내용 |
|---|---|
| Figma | 은행 홈부터 업무 완료까지 이어지는 UI/UX 화면 디자인 |
| Adobe Firefly | 팀원이 작성한 스토리보드에 맞춰 홍보 영상용 이미지와 영상 장면 생성 |
| ChatGPT | 원하는 움직임이 나오지 않을 때 영상 생성 프롬프트 보완 |
| Adobe Premiere Pro | 생성한 이미지와 영상 편집, 자막 추가 |

## 대표 프로젝트 — 외국인 특화 스마트 화면 가이드 챗봇

### 프로젝트 기본 정보

| 항목 | 내용 |
|---|---|
| 프로젝트 | AX해커톤 |
| 진행 기간 | 3일 |
| 참여 형태 | 5인 팀 프로젝트 |
| 진행 상태 | 프로젝트 완료 |
| 개인 담당 | UI/UX 디자인, AI 홍보 영상 제작 |

### 대상 사용자와 문제

한국어 금융 용어와 국내 은행 절차에 익숙하지 않은 외국인 고객을 주요 대상으로 설정했습니다.

은행 앱에서 안내 문구를 이해하지 못하거나, 설명을 읽어도 실제로 어떤 버튼을 눌러야 하는지 찾기 어려운 상황에 주목했습니다. AI의 도움으로 해결하지 못한 경우에는 상담원에게 이전 상황을 다시 설명해야 하는 문제도 함께 다루고자 했습니다.


### 문제와 서비스 기능의 연결

| 해결하려는 문제 | 기획한 기능 | 문제를 다루는 방식 |
|---|---|---|
| 고객이 이용 중 막혀도 도움을 요청하기 어렵다. | AI의 막힘 감지와 선제 안내 | 고객이 어려움을 겪는 상황에서 먼저 도움을 제안한다. |
| 설명만으로 다음에 누를 위치를 찾기 어렵다. | Spotlight 화면 안내 | 화면의 특정 영역을 강조하고 단계별 행동을 안내한다. |
| 상담원에게 이전 상황을 다시 설명해야 한다. | 이용 기록을 동반한 상담원 연결 | 이전 이용 맥락과 함께 상담으로 이어지도록 한다. |

위 표는 서비스 기획을 설명합니다. 각 기능의 실제 작동 범위는 별도로 구분합니다.

### 현재 결과와 확인 범위

UI/UX 화면은 다음 흐름을 담고 있습니다.

**은행 홈 → AI 대화 → 안내 시작 → Spotlight 안내 → 업무 완료**

개인 디자인 작업본 5종과 AI 홍보 영상을 제작했습니다. UI는 이후 다른 팀원이 발전시켜 최종 디자인으로 완성했습니다.

첨부 화면으로 화면 구성과 안내 흐름을 확인할 수 있습니다.

## 개인 기여와 협업 범위

| 작업 | 나의 기여 | 다른 팀원 기여 |
|---|---|---|
| UI/UX 디자인 | Figma로 주요 화면 5종 디자인 | 제 작업본을 발전시켜 최종 디자인 완성 |
| 홍보 영상 | 이미지 제작, AI 영상 생성, 편집, 자막 작업 | 스토리보드 작성 |

최종 UI 디자인은 팀의 공동 결과물입니다. 아래 개인 작업 화면은 제가 제작한 버전이며, 팀원이 수정한 최종 디자인과 구분합니다.


## 작업 과정과 내가 만든 변화

### 1. 사용자 동선을 화면으로 구체화

**작업 출발점**  
외국인 고객이 은행 앱에서 다음 행동을 쉽게 파악할 수 있도록 돕는 서비스 구상을 바탕으로 작업했습니다.

**수행한 작업**  
간단한 인터페이스와 직관적인 동선을 지향하며 Figma로 다음 화면을 디자인했습니다.

| 직접 디자인한 화면 | 화면에 담은 내용 |
|---|---|
| 은행 홈 | 계좌 정보, 주요 업무, AI 도움 요청 진입점 |
| AI 대화 | 업무 입력 영역과 빠른 질문 |
| 안내 시작 | 화면 안내를 시작할지 선택하는 영역 |
| Spotlight 안내 | 특정 영역 강조와 단계별 안내 문구 |
| 업무 완료 | 안내 절차를 마쳤음을 알리는 메시지 |

**작업 결과**  
서비스 이용 순서를 5개 화면으로 표현했습니다. 특히 Spotlight 화면에서는 주변을 어둡게 하고 특정 영역을 강조해 다음 행동의 위치를 보여주도록 구성했습니다.

이를 통해 서비스의 안내 흐름을 시각적으로 설명할 수 있는 작업본을 만들었습니다. 실제 사용자에게 더 쉬워졌는지는 검증하지 않았습니다.

### 2. 스토리보드를 이미지와 영상으로 제작

**작업 출발점**  
다른 팀원이 작성한 홍보 영상 스토리보드를 바탕으로 제작을 시작했습니다.

**수행한 작업**

1. Adobe Firefly로 필요한 이미지를 생성했습니다.
2. Adobe Firefly로 영상 장면과 움직임을 생성했습니다.
3. 의도와 다른 움직임이 나오면 ChatGPT를 활용해 프롬프트를 보완하고 재생성했습니다.
4. Premiere Pro에서 장면을 편집하고 자막을 추가했습니다.

**작업 결과**  
스토리보드 내용을 이미지와 영상 장면으로 제작하고, 편집과 자막 작업을 거쳐 홍보 영상을 완성했습니다.

### 3. 생성 영상의 움직임 보완

영상 생성 과정에서 움직임이 부자연스럽거나 원하는 동작과 다르게 나오는 경우가 있었습니다.

ChatGPT에 질문하며 프롬프트 작성 방식을 살펴보고 표현을 보완한 뒤, Firefly에서 다시 생성했습니다. 재생성 결과 원하는 움직임을 표현할 수 있었다고 경험했습니다.

이는 제작 중 결과물을 보고 수정한 경험에 대한 본인 설명입니다. 구체적인 장면, 당시 프롬프트 원문, 시도 횟수와 수정 전후 비교 자료는 현재 확인되지 않아 수치나 세부 사례를 추가하지 않았습니다.

### 근거의 범위와 미확인 사항

| 항목 | 현재 확인 범위 |
|---|---|
| 개인 UI/UX 화면 | 원본 화면 5장이 제공됐으며, 본인 작업이라고 설명했습니다. |
| 팀 최종 디자인 | 팀원이 수정한 최종 화면 1장이 제공됐습니다. |
| 영상 제작 역할 | 본인 설명을 기준으로 정리했습니다. |
| 완성 영상 | 파일은 제공됐지만 전체 영상 내용은 직접 검토되지 않았습니다. |
| 실제 기능 테스트 | 테스트 조건, 행동, 결과를 확인할 기록은 제공되지 않았습니다. |
| 코드·PR·Figma 변경 기록 | 현재 문서에 연결된 자료가 없습니다. |
| 사용자 반응·정량적 성과 | 확인된 자료가 없어 성과로 제시하지 않습니다. |

## 배운 점

### 개인 작업을 팀 결과물로 이어가는 협업

제가 제작한 UI 화면에 다른 팀원이 추가 작업을 진행해 최종 디자인을 완성했습니다. 제 작업이 다른 팀원의 작업과 연결되어 결과물로 발전하는 과정을 경험했으며, 이번 프로젝트의 주요 배움으로 협업을 꼽고 있습니다.

### 생성 결과를 보고 프롬프트 보완하기

원하는 움직임이 처음부터 나오지 않는 상황에서 ChatGPT를 활용해 프롬프트를 보완하고 다시 생성했습니다. 원하는 결과를 얻기 위해 생성 결과를 살펴보고 표현을 수정하는 과정을 경험했습니다.

## 현재 한계와 개선 계획

### 현재 한계

화면을 디자인할 때 직관적인 구성과 사용자 동선에 집중했습니다. 그 과정에서 시각적인 아름다움까지 충분히 발전시키지 못한 점이 아쉬움으로 남았습니다.

따라서 현재 작업은 안내 흐름을 보여주는 개인 디자인 결과물로 제시하며, 시각적 완성도를 더 높일 여지가 있다고 생각합니다. 외국인 사용자가 실제로 이해하기 쉬운지 확인한 테스트 자료도 없습니다.

### 다음 개선 계획

앞으로는 직관적인 사용 흐름을 유지하면서 시각적 완성도를 함께 높이는 방향으로 디자인을 고도화하고자 합니다.

이를 위한 다음 작업과 완료 확인 기준은 아래와 같이 계획합니다. 아직 수행한 작업은 아닙니다.

| 개선 작업 | 완료 확인 기준 |
|---|---|
| 기존 개인 작업 화면 5종을 다시 검토하고 시각적 개선안 제작 | 화면별 수정 전후 이미지와 변경 이유 정리 |
| 수정안에서 기존 안내 흐름 유지 여부 점검 | 은행 홈부터 업무 완료까지 5개 화면의 순서와 다음 행동 위치를 설명할 수 있는지 확인 |

위 기준은 디자인 수정 작업의 완료를 확인하기 위한 기준이며, 실제 사용성 향상을 입증하는 기준은 아닙니다.

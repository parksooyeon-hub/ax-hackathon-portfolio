# ax-hackathon-portfolio
외국인 특화 은행 앱 가이드 챗봇 — UI/UX 디자인 및 AI 홍보 영상 제작
# AX해커톤 — 외국인 특화 스마트 화면 가이드 챗봇
**박수연 | UI/UX 디자인 · AI 홍보 영상 제작**

## 1. 프로젝트 개요
외국인 고객이 은행 앱에서 겪는 언어와 금융 절차의 어려움을 줄이기 위한 프로젝트입니다. AI가 고객의 막힘을 감지하고, 필요한 화면을 Spotlight로 강조해 안내하며, 해결되지 않으면 이용 기록과 함께 상담원에게 연결하는 서비스를 기획했습니다.

- **진행 기간:** 3일
- **팀 규모:** 5명
- **진행 상태:** 완료
- **담당 역할:** UI/UX 디자인, AI 홍보 영상 제작

## 2. 대상 사용자와 해결하려는 문제
한국어 금융 용어에 익숙하지 않거나 국내 은행의 본인인증·송금·계좌 개설 절차를 처음 경험하는 외국인 고객을 주요 대상으로 설정했습니다.

해결하려는 문제는 다음과 같습니다.

- 금융 용어와 안내 문구, 오류 메시지를 이해하기 어렵다.
- 설명을 읽어도 실제 화면에서 누를 버튼이나 입력할 항목을 찾기 어렵다.
- 자신이 겪는 문제를 설명하기 어려워 도움 요청에 어려움이 있다.
- 상담원 연결 후 이전에 시도한 과정과 오류 상황을 다시 설명해야 한다.

이는 프로젝트에서 설정한 문제이며, 사용자 조사로 검증한 결과는 아닙니다.

## 3. 서비스 안내 흐름
서비스는 다음 흐름으로 기획했습니다.

**고객의 막힘 감지 → Spotlight 화면 안내 → 미해결 시 이용 기록과 함께 상담원 연결**

제가 디자인한 화면은 다음 이용 흐름을 담고 있습니다.

**은행 홈 → AI 대화 → 화면 안내 시작 → Spotlight 안내 → 업무 완료**

첨부한 디자인 화면에서 이 흐름을 확인할 수 있습니다. 자동 막힘 감지와 상담원 연결 기능의 실제 작동 범위는 현재 자료만으로 확인되지 않았습니다.

## 4. 나의 역할과 팀원 기여

| 구분 | 담당 내용 |
|---|---|
| **나의 기여** | 은행 홈, AI 대화, 안내 시작, Spotlight 안내, 업무 완료 화면 등 UI/UX 화면 5종 디자인 |
| **나의 기여** | 홍보 영상용 이미지 제작, AI 영상 장면 생성, 영상 편집 및 자막 작업 |
| **팀원 기여** | 홍보 영상 스토리보드 작성 |
| **팀원 기여** | 제가 제작한 디자인을 추가로 발전시켜 최종 디자인 완성 |

UI/UX 화면 5종은 제가 제작한 작업본이며, 이후 다른 팀원이 수정한 화면은 팀의 최종 디자인으로 구분합니다.

## 5. UI/UX 디자인 과정과 결과

### 디자인 방향
외국인 고객에게는 간단하고 직관적인 인터페이스가 필요하다고 판단했습니다. 사용자가 다음 행동을 쉽게 파악할 수 있도록 화면 구성과 사용자 동선을 고려해 Figma로 디자인했습니다.

### 주요 화면
- **은행 홈:** 계좌 정보와 이체 등 주요 업무, AI 도움 요청 진입점 구성
- **AI 대화:** 업무 입력과 빠른 질문을 통한 요청 화면 구성
- **안내 시작:** 화면 안내를 시작할지 선택하는 화면 구성
- **Spotlight 안내:** 화면의 특정 영역을 강조하고 단계별 안내 문구 제공
- **업무 완료:** 안내 절차를 마쳤음을 알리는 화면 구성

간결한 인터페이스와 직관적인 동선을 지향했으며, 실제 사용성 개선 여부를 검증한 자료는 없습니다.

## 6. AI 홍보 영상 제작 과정
팀원이 작성한 스토리보드를 바탕으로 이미지와 영상 장면을 제작했습니다.

1. **이미지 제작:** Adobe Firefly로 영상에 사용할 이미지 생성
2. **AI 영상 생성:** Adobe Firefly로 장면과 움직임 생성
3. **프롬프트 보완:** ChatGPT를 활용해 원하는 움직임을 전달하는 프롬프트 수정
4. **편집 및 자막:** Premiere Pro에서 생성한 이미지와 영상을 편집하고 자막 추가

스토리보드 이후의 이미지 제작, AI 영상 생성, 편집, 자막 작업을 담당해 홍보 영상을 완성했습니다.

## 7. 제작 중 문제와 해결
AI 영상 생성 과정에서 움직임이 부자연스럽거나 원하는 동작이 나오지 않는 어려움이 있었습니다.

이를 해결하기 위해 ChatGPT에 질문하며 프롬프트 작성 방식을 살펴보고, 표현을 보완해 영상을 다시 생성했습니다. 이 과정을 통해 의도한 움직임이 반영된 장면을 제작했습니다.

## 8. 결과물과 사용 도구

- 직접 제작한 UI/UX 화면 5종
- 제 디자인을 바탕으로 팀원이 발전시킨 최종 디자인
- 이미지 제작부터 영상 생성·편집·자막까지 담당한 AI 홍보 영상

| 도구 | 사용 내용 |

| Adobe Premiere Pro | 영상 편집 및 자막 작업 |
